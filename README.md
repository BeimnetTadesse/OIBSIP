# AI & Data Science Internship Projects

A collection of machine learning and data science projects completed as part of the **Oasis Infobyte (OIBSIP) Internship Program**.

This repository demonstrates practical applications of supervised machine learning, data preprocessing, exploratory data analysis, model training, evaluation, and prediction.

## Projects

| Task | Project | Description | Techniques |
|---|---|---|---|
| 1 | [Iris Flower Classification](./task-1-iris-classification/) | Classifies Iris flowers into three species based on their physical measurements. | Decision Tree, Classification |
| 3 | [Car Price Prediction](./task-3-car-price-prediction/) | Predicts used car selling prices based on vehicle specifications. | Linear Regression, Random Forest, Regression |
| 4 | [SMS Spam Detection](./task-4-email-spam-detection/) | Classifies SMS messages as spam or legitimate using text analysis. | NLP, TF-IDF, Naive Bayes, Logistic Regression |

## Technologies Used

- **Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **NLP:** NLTK
- **Environment:** Jupyter Notebook, VS Code
- **Model Persistence:** Joblib

## Skills Demonstrated

- Data exploration and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering and encoding
- Supervised machine learning
- Classification and regression
- Model evaluation and comparison
- Natural Language Processing
- Data visualization
- Model saving and prediction
